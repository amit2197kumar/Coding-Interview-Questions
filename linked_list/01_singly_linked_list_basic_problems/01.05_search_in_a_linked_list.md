# Search In A Linked List

**Problem Link:** [Search In A Linked List](https://www.naukri.com/code360/problems/search-in-a-linked-list_975381)

## Iterative Solution

```java
public class Solution {
    public static int searchInLinkedList(Node head, int k) {
        if (head == null) return 0;

        while (head != null) {
            if (head.data == k) return 1;
            head = head.next;
        }
        return 0;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the code iterates through the entire linked list once using a while loop, checking each node's data to see if it matches the target value k.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not scale with the size of the input; it only uses a few variables (head, k, and the loop control variables).

## Recursive Solution

```java
public class Solution {
    public static int searchInLinkedList(Node head, int k) {
        if (head == null) return 0;
        return head.data == k ? 1 : searchInLinkedList(head.next, k);
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function traverses the entire linked list recursively until it finds the target value k or reaches the end of the list. Each recursive call processes one node in the linked list, so the time complexity is linear with respect to the number of nodes.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the number of nodes in the linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the linked list is traversed until the target value k is found or the end of the list is reached, the maximum depth of recursion is equal to the number of nodes in the linked list. Therefore, the space required on the call stack is proportional to the number of nodes in the linked list.
