# Count Nodes Of Linked List

**Problem Link:** [Count Nodes Of Linked List](https://www.naukri.com/code360/problems/count-nodes-of-linked-list_5884)

## Iterative Solution

```java
public class Solution {
    public static int length(Node head){
        if (head == null) return 0;
        
        int length = 0;
        while(head != null) {
            length++;
            head = head.next;
        }
        return length;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the code iterates through the entire linked list once using a while loop, incrementing the length variable for each node.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not scale with the size of the input; it only uses a single integer variable (length) to store the length of the linked list. 

## Recursive Solution

```java
public class Solution {
    public static int length(Node head){
        if (head == null) return 0;
        
        return length(head.next) + 1;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function traverses the entire linked list recursively until it reaches the end. Each recursive call processes one node in the linked list, so the time complexity is linear with respect to the number of nodes.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the number of nodes in the linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the linked list is traversed until the last node is reached, the maximum depth of recursion is equal to the number of nodes in the linked list. Therefore, the space required on the call stack is proportional to the number of nodes in the linked list.
