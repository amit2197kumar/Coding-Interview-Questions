# Delete Last Node Of Linked List

**Problem Link:** [Delete Last Node Of Linked List](https://www.naukri.com/code360/problems/delete-node-of-linked-list_8160463)

## Iterative Solution

```java
public class Solution {
    public static Node deleteLast(Node head){
        if (head == null) return null;
        if (head.next == null) return null;

        Node first = head;
        Node second = head.next;

        while(second.next != null) {
            first = second;
            second = second.next;
        }
        first.next = null;
        return head;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the code traverses the entire linked list once to find the second-to-last node, which requires iterating through the list until reaching the end.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list.

## Recursive Solution

```java
public class Solution {
    public static Node deleteLast(Node head){
        if (head == null) return null;
        if (head.next == null) return null;

        head.next = deleteLast(head.next);
        return head;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function traverses the entire linked list recursively until it reaches the last node. Each recursive call processes one node in the linked list, so the time complexity is linear with respect to the number of nodes.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the number of nodes in the linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the linked list is traversed until the last node is reached, the maximum depth of recursion is equal to the number of nodes in the linked list. Therefore, the space required on the call stack is proportional to the number of nodes in the linked list.
