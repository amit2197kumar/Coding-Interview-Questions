# Insert Node At The Beginning

**Problem Link:** [Insert Node At The Beginning](https://www.naukri.com/code360/problems/insert-node-at-the-beginning_8144739)

## Solution

```java
public class Solution
{
    public static Node insertAtFirst(Node list, int newValue) {
        Node newNode = new Node(newValue);
        newNode.next = list;
        return newNode;
    }
}
```

Time Complexity: `O(1)`
- The time complexity of the given code is O(1), which means it's constant time complexity. This is because regardless of the size of the linked list (list), the code always performs a constant number of operations to insert the new node at the beginning of the list.

Space Complexity: `O(1)`
- The space complexity is also O(1). This is because the code only creates a single new node (newNode) and doesn't use any additional data structures or consume additional memory proportional to the size of the input.
