# Cycle Detection In A Singly Linked List

**Problem Link:** [Cycle Detection In A Singly Linked List](https://www.naukri.com/code360/problems/cycle-detection-in-a-singly-linked-list_628974)

## Iterative Solution

```java
public class Solution {
    public static boolean detectCycle(Node head) {
        if (head == null || head.next == null)
            return false;

        Node slow = head;
        Node fast = head.next;

        while(fast != null && fast.next != null) {
            if (slow == fast) 
                return true;
            
            slow = slow.next;
            fast = fast.next.next;
        }
        return false;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because both the slow and fast pointers traverse the entire linked list. The slow pointer moves one node at a time, while the fast pointer moves two nodes at a time. Therefore, the fast pointer covers twice the distance as the slow pointer, and when the fast pointer meets the slow pointer (indicating a cycle), the loop terminates. Since both pointers traverse the list only once, the time complexity is linear.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not depend on the size of the input; it only uses a few variables (head, slow, fast, and loop control variables).

## Recursive Solution

```java
public class Solution {
    public static boolean detectCycle(Node head) {
        if (head == null || head.next == null)
            return false;

        return detectCycle(head, head.next);
    }

    public static boolean detectCycle(Node slow, Node fast) {
        if (fast == null || fast.next == null)
            return false;

        if (slow == fast)
            return true;
            
        return detectCycle(slow.next, fast.next.next);
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function detectCycle(Node slow, Node fast) is called recursively, and in each recursive call, the fast pointer moves two nodes ahead while the slow pointer moves one node ahead. This effectively halves the search space in each step, making the time complexity linear with respect to the number of nodes.

Space Complexity: `O(n)`
- Since the algorithm is implemented recursively, the space complexity depends on the maximum depth of the recursion stack. In the worst case, when there is a cycle and the pointers move towards each other, the maximum depth of the recursion stack is O(n), where n is the number of nodes in the list. Therefore, the space complexity is O(n) in the worst case.
