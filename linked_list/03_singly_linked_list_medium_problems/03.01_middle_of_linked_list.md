# Middle Of Linked List

**Problem Link:** [Middle Of Linked List](https://www.naukri.com/code360/problems/middle-of-linked-list_973250)

## Iterative Solution

```java
public class Solution {
    public static Node findMiddle(Node head) {
        if (head == null || head.next == null) return head;

        Node slow = head;
        Node fast = head;

        while(fast !=null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;
        }

        return slow;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because both the slow and fast pointers traverse the entire linked list. The slow pointer moves one node at a time, while the fast pointer moves two nodes at a time. Therefore, the fast pointer covers twice the distance as the slow pointer, and when the fast pointer reaches the end of the list (or null), the slow pointer will be at the middle node. Since both pointers traverse the list only once, the time complexity is linear.

Space Complexity: `O(1)`
- The space complexity of the given code is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not depend on the size of the input; it only uses a few variables (head, slow, fast, and loop control variables). 

## Recursive Solution

```java
public class Solution {
    public static Node findMiddle(Node head) {
        if (head == null || head.next == null) 
            return head;
        return findMiddle(head, head);
    }

    public static Node findMiddle(Node slow, Node fast) {
        if (fast == null || fast.next == null) 
            return slow;
        return findMiddle(slow.next, fast.next.next);
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function findMiddle(Node slow, Node fast) is called recursively, and in each recursive call, the fast pointer moves two nodes ahead while the slow pointer moves one node ahead. This effectively halves the search space in each step, making the time complexity linear with respect to the number of nodes.

Space Complexity: `O(n)`
- The space complexity is O(1) because the function uses recursion, O(n), where n is the number of nodes in the linked list. Each recursive call traverses half of the remaining nodes in the list until reaching the middle. Therefore, the time complexity is linear with respect to the number of nodes in the list.
