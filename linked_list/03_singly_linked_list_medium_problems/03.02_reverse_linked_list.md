# Reverse Linked List

**Problem Link:** [Reverse Linked List](https://www.naukri.com/code360/problems/reverse-linked-list_920513)

## Iterative Solution

```java
public class Solution {
    public static Node reverseLinkedList(Node head) {
        if (head == null || head.next == null)
            return head;

        Node prev = null;
        Node curr = head;
        Node next;

        while(curr != null) {
            next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }

        return prev;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the code iterates through each node of the list once in the while loop, reversing the pointers and updating the prev and next references.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not scale with the size of the input; it only uses a few variables (prev, curr, next, and loop control variables).

## Recursive Solution

```java
public class Solution {
    public static Node reverseLinkedList(Node head) {
        if (head == null || head.next == null)
            return head;

        return reverseLinkedList(head, null);
    }

    public static Node reverseLinkedList(Node curr, Node prev) {
        if (curr == null)
            return prev;

        Node nextNode = curr.next;
        curr.next = prev;

        return reverseLinkedList(nextNode, curr);
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function reverseLinkedList(Node curr, Node prev) is called recursively once for each node in the list. Each recursive call processes one node in the list until reaching the end.

Space Complexity: `O(n)`
- The space complexity is O(n), where n is the number of nodes in the linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the recursion depth is equal to the number of nodes in the list, the space required on the call stack is proportional to the number of nodes in the list.
