# Delete Last Node Of A Doubly Linked List

**Problem Link:** [Delete Last Node Of A Doubly Linked List](https://www.naukri.com/code360/problems/delete-last-node-of-a-doubly-linked-list_8160469)

## Iterative Solution

```java
public class Solution {
    public static Node deleteLastNode(Node head) {
        if (head == null || head.next == null) return null;

        Node first = head;
        Node second = head.next;

        while (second.next != null) {
            first = second;
            second = second.next;
        }

        second.prev = null;
        first.next = null;

        return head;
    }
}

```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the code traverses the entire linked list once to find the second-to-last node, which requires iterating through the list until reaching the end.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not scale with the size of the input; it only uses a few variables (head, first, second, and loop control variables).

## Recursive Solution

```java
public class Solution {
    public static Node deleteLastNode(Node head) {
        if (head == null || head.next == null) return null;

        if (head.next.next == null) {
            head.next.prev = null;
            head.next = null;
            return head;
        }

        head.next = deleteLastNode(head.next);
        return head;
    }
}

```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function deleteLastNode is called recursively once for each node in the worst case. Each recursive call processes one node in the linked list until reaching the last node.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the number of nodes in the linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the recursion depth is equal to the number of nodes in the linked list, the space required on the call stack is proportional to the number of nodes in the linked list.
