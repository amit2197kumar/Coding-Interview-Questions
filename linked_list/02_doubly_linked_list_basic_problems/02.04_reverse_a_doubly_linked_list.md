# Reverse A Doubly Linked List

**Problem Link:** [Reverse A Doubly Linked List](https://www.naukri.com/code360/problems/reverse-a-doubly-linked-list_1116098)

## Iterative Solution

```java
public class Solution {
    public static Node reverseDLL(Node head) {
        if (head == null || head.next == null) return head;

        Node node1 = head;
        Node node2 = head.next;
        Node node3 = head.next.next;

        node1.next = null;
        node2.prev = null;

        while (node3 != null) {
            node1.prev = node2;
            node2.next = node1;

            node1 = node2;
            node2 = node3;
            node3 = node3.next;
        }

        node1.prev = node2;
        node2.next = node1;

        return node2;
    }
}
```
```java
public class Solution {
    public static Node reverseDLL(Node head) {
        Node prev = null;
        Node current = head;

        while (current != null) {
            Node nextNode = current.next;
            current.next = prev;
            current.prev = nextNode;
            prev = current;
            current = nextNode;
        }

        return prev;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the doubly linked list. This is because the code iterates through each node of the list once in the while loop.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input doubly linked list. The space used does not scale with the size of the input.

## Recursive Solution

```java
public class Solution {
    public static Node reverseDLL(Node head) {
        if (head == null || head.next == null) {
            return head;
        }

        Node reversedSublistHead = reverseDLL(head.next);

        head.next.next = head;
        head.prev = head.next;
        head.next = null;

        return reversedSublistHead;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the doubly linked list. This is because the function reverseDLL is called recursively once for each node in the worst case. Each recursive call processes one node in the linked list, so the time complexity is linear with respect to the number of nodes.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the number of nodes in the doubly linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the recursion depth is equal to the number of nodes in the doubly linked list, the space required on the call stack is proportional to the number of nodes in the list.
