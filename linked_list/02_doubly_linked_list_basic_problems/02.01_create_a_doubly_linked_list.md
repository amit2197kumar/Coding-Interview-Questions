# Create A Doubly Linked List

**Problem Link:** [Create A Doubly Linked List](https://www.naukri.com/code360/problems/introduction-to-doubly-linked-list_8160413)

## Iterative Solution

```java
public class Solution {
    public static Node constructDLL(int []arr) {
        if (arr == null || arr.length == 0) return null;

        Node head = new Node(arr[0]);
        Node currNode = head;

        for (int i=1; i<arr.length; i++) {
            Node newNode = new Node(arr[i]);

            currNode.next = newNode;
            newNode.prev = currNode;

            currNode = newNode;
        }
        return head;
    }
}

```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the length of the input array arr. This is because the code iterates through the entire array once in the for loop to construct the doubly linked list. Each iteration involves creating a new node and updating the next and prev pointers, which takes constant time.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the length of the input array arr. This is because the code creates a new node for each element in the array, resulting in n nodes in the doubly linked list.

## Recursive Solution

```java
public class Solution {
    public static Node constructDLL(int []arr) {
        if (arr == null || arr.length == 0) return null;
        return constructDLL(arr, 0, null);
    }

    public static Node constructDLL(int []arr, int index, Node prevNode) {
        if (arr.length == index) return null;

        Node newNode = new Node(arr[index]);
        newNode.prev = prevNode;
        newNode.next = constructDLL(arr, ++index, newNode);

        return newNode;
    }
}
```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the length of the input array arr. This is because the function constructDLL(int[] arr, int index, Node prevNode) is called recursively once for each element in the array. Each recursive call processes one element and creates a corresponding node in the doubly linked list.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the length of the input array arr. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the recursion depth is equal to the length of the array, the space required on the call stack is proportional to the length of the array.
