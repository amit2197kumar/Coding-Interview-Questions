# Insert At End Of Doubly Linked List

**Problem Link:** [Insert At End Of Doubly Linked List](https://www.naukri.com/code360/problems/insert-at-end-of-doubly-linked-list_8160464)

## Iterative Solution

```java
public class Solution {
    public static Node insertAtTail(Node head, int k) {
        if (head == null) return new Node(k);
        Node currNode = head;

        while (currNode.next != null)
            currNode = currNode.next;

        Node newNode = new Node(k);
        newNode.prev = currNode;
        currNode.next = newNode;

        return head;
    }
}

```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the code iterates through the entire linked list once using a while loop to find the last node. The loop continues until currNode.next becomes null, indicating the last node.

Space Complexity: `O(1)`
- The space complexity is O(1), which means it's constant space complexity. This is because the code only uses a constant amount of extra space regardless of the size of the input linked list. The space used does not scale with the size of the input; it only uses a few variables (head, currNode, newNode, and loop control variables).

## Recursive Solution

```java
public class Solution {
    public static Node insertAtTail(Node head, int k) {
        if (head == null) return new Node(k);

        if (head.next == null) {
            Node newNode = new Node(k);
            newNode.prev = head;
            head.next = newNode;
            return head;
        }
        head.next = insertAtTail(head.next, k);
        return head;
    }
}

```

Time Complexity: `O(n)`
- The time complexity of the given code is O(n), where n is the number of nodes in the linked list. This is because the function traverses the entire linked list recursively until it reaches the last node. Each recursive call processes one node in the linked list, so the time complexity is linear with respect to the number of nodes.

Space Complexity: `O(n)`
- The space complexity is also O(n), where n is the number of nodes in the linked list. This is because the function uses recursion, and each recursive call adds a new frame to the call stack. In the worst case, where the linked list is traversed until the last node is reached, the maximum depth of recursion is equal to the number of nodes in the linked list.
